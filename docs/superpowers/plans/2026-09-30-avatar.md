# Avatar Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship a Chakra-style compound `Avatar` (`Avatar` / `AvatarImage` / `AvatarFallback` / `AvatarOverlay`) on Ark UI, make it click-to-upload through a headless `FileUploadTrigger asChild`, and migrate `NavRailItem` onto it.

**Architecture:** Avatar wraps `@ark-ui/react/avatar`. Ark runs the image-load state machine and toggles `data-state` on the image and the fallback. Every visual state is CSS: `has-[…]` / `group/avatar` selectors, with no JS status in DS code. FileUpload gains a Slot-style `asChild` trigger mode and a `useFilePreviewUrl` hook, so "click the avatar to pick a photo" is pure composition.

**Tech Stack:** React 19, TypeScript strict, `@ark-ui/react` 5.38.0, Tailwind v4, CVA, Vitest + Testing Library (jsdom), Playwright (CI only), Storybook 10 (`storybook-react-rsbuild`), `@figma/code-connect`.

**Spec:** `docs/superpowers/specs/2026-09-30-avatar-design.md`. Read it before starting any task.

## Global Constraints

- Sizes are exactly `xs` (24px, `rounded-8`, initials `text-2xs`) and `sm` (32px, `rounded-12`, initials `text-xs`). The default is `sm`. No other sizes, and no shape prop.
- The fallback content order is `children`, then `getInitials(name)` when it is non-empty, then `<Icon size='md' />` (default `UserRound`).
- The hover wash token is `--color-component-avatar-overlay`:
  - light: `--alpha(var(--color-white) / 80%)`
  - dark: `--alpha(var(--color-slate-950) / 80%)`
- The Avatar root renders a `<span>`, or the consumer child when `asChild`. Put `data-slot='avatar'` **before** `{...props}` so an incoming `data-slot` wins. Never style with `[data-slot=avatar]`; use `group/avatar`.
- Avatar reads `data-testid` only from its own prop, never from the cascade, so it never duplicates a parent id. It wraps the root in `TestIdProvider`, and the parts use `useTestId('image' | 'fallback' | 'overlay')`.
- Always render `AvatarImage`, even without `src`. Never render it conditionally.
- Coding rules:
  - no `any`;
  - no inline styles;
  - no hardcoded colours;
  - no `React.forwardRef`;
  - named exports only;
  - `cn()` for classes;
  - CVA in `classes.ts`;
  - `displayName` on every part.
- Metrics contract: no analytics props. The full attribute surface lands on the real node, and handlers compose; never use `stopPropagation`.
- **E2E runs in CI only.** Never run `e2e:docker` locally. Screenshot baselines come from a pushed commit containing `[update-screenshots]`, and pushing needs the user's go-ahead.
- Typecheck with `pnpm --filter @wallarm-org/design-system exec tsc --build tsconfig.app.json --noEmit`. The `typecheck` script is a no-op.
- Commits follow Conventional Commits and end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
- Crop dialog, AvatarGroup, badges, colour-by-name and drag-and-drop onto the avatar are **out of scope**.

## Review Focus

1. **Double Slot (`FileUploadTrigger asChild` → `Avatar asChild` → `<button>`).** `data-slot='file-upload-trigger'`, `data-testid`, `disabled`, `aria-describedby`, the consumer `onClick` and the picker opening must all survive both layers. Tested in Task 6.
2. **`src` transitions: undefined → blob preview → server URL.** The fallback must show only while the new image is loading and must never get stuck hidden. Tested in Task 2 (rerender) and Task 6 (pick → preview).
3. **A name that yields no initials** (`'   '`, `''`) shows the icon, not an empty plate. Tested in Task 2.
4. **An Avatar inside a test-id cascade without its own id** (NavRail) must not copy the parent's `data-testid`. Tested in Task 7.
5. **Disabled interactive avatar.** No overlay on hover, and the picker doesn't open. Tested in Task 6 (picker) and checked visually in Task 8.

```ts
const segmenter =
  typeof Intl !== 'undefined' && 'Segmenter' in Intl
    ? new Intl.Segmenter(undefined, { granularity: 'grapheme' })
    : undefined;

// Grapheme-safe: an emoji or a letter with a combining mark stays whole.
const firstGrapheme = (word: string): string => {
  if (!segmenter) return Array.from(word)[0] ?? '';
  const first = segmenter.segment(word)[Symbol.iterator]().next();
  return first.done ? '' : first.value.segment;
};

/** Avatar initials: the first grapheme of the first and of the last word, upper-cased. */
export const getInitials = (name: string): string => {
  const words = name.trim().split(/\s+/).filter(Boolean);
  const first = words.at(0);
  if (!first) return '';
  const last = words.length > 1 ? (words.at(-1) ?? '') : '';
  return (firstGrapheme(first) + firstGrapheme(last)).toLocaleUpperCase();
};
```

```ts
export const avatarVariants = cva(
  cn(
    // Parts share one grid cell (like the NavRail plate), so the root's own tints show through.
    'group/avatar inline-grid shrink-0 place-items-center overflow-hidden align-middle *:col-start-1 *:row-start-1',
```

- [ ] **Step 4: Implement `Avatar.tsx`**

```tsx
import type { FC, HTMLAttributes, Ref } from 'react';
import { Avatar as ArkAvatar } from '@ark-ui/react/avatar';
import type { VariantProps } from 'class-variance-authority';
import { cn } from '../../utils/cn';
import { type TestableProps, TestIdProvider } from '../../utils/testId';
import { avatarVariants } from './classes';

export type AvatarStatusChangeDetails = ArkAvatar.StatusChangeDetails;

export interface AvatarProps
  extends HTMLAttributes<HTMLElement>,
    VariantProps<typeof avatarVariants>,
    TestableProps {
  ref?: Ref<HTMLElement>;
  /** Render the single child element as the root — e.g. a `<button>` inside `FileUploadTrigger asChild`. */
  asChild?: boolean;
  onStatusChange?: (details: AvatarStatusChangeDetails) => void;
}

/**
 * A user's photo on a rounded plate, falling back to initials or an icon while the photo loads,
 * when it fails, or when there is none.
 */
export const Avatar: FC<AvatarProps> = ({
  ref,
  size,
  asChild = false,
  onStatusChange,
  className,
  children,
  'data-testid': testId,
  ...props
}) => {
  // A labelled standalone avatar is an image; an asChild root keeps its own role (e.g. button).
  const role = props.role ?? (props['aria-label'] && !asChild ? 'img' : undefined);

  return (
    <TestIdProvider value={testId}>
      <ArkAvatar.Root
        // Before the spread, so a data-slot passed in (FileUploadTrigger, NavRail) wins.
        data-slot='avatar'
        {...props}
        ref={ref as Ref<HTMLDivElement>}
        role={role}
        data-testid={testId}
        onStatusChange={onStatusChange}
        className={cn(avatarVariants({ size }), className)}
        asChild
      >
        {/* Ark's default root is a div, which is invalid inside a button. */}
        {asChild ? children : <span>{children}</span>}
      </ArkAvatar.Root>
    </TestIdProvider>
  );
};

Avatar.displayName = 'Avatar';
```

- [ ] **Step 6: Implement `AvatarFallback.tsx`**

```tsx
import type { ComponentType, FC, HTMLAttributes, Ref } from 'react';
import { Avatar as ArkAvatar } from '@ark-ui/react/avatar';
import { type SvgIconProps, UserRound } from '../../icons';
import { cn } from '../../utils/cn';
import { getInitials } from '../../utils/getInitials';
import { useTestId } from '../../utils/testId';
import { avatarFallbackClassNames } from './classes';

export interface AvatarFallbackProps extends HTMLAttributes<HTMLSpanElement> {
  ref?: Ref<HTMLSpanElement>;
  /** Initials are taken from this: first letter of the first and of the last word. */
  name?: string;
  /** Shown when there are no children and `name` gives no initials. */
  icon?: ComponentType<SvgIconProps>;
}

/** Shown while the photo loads, when it fails, and when there is none. */
export const AvatarFallback: FC<AvatarFallbackProps> = ({
  ref,
  name,
  icon: Icon = UserRound,
  className,
  children,
  ...props
}) => {
  const testId = useTestId('fallback');
  const initials = name ? getInitials(name) : '';

  return (
    <ArkAvatar.Fallback
      {...props}
      ref={ref}
      // The image's alt or the root's label names the person; initials read aloud are noise.
      aria-hidden
      data-slot='avatar-fallback'
      data-testid={testId}
      className={cn(avatarFallbackClassNames, className)}
    >
      {children ?? (initials || <Icon size='md' />)}
    </ArkAvatar.Fallback>
  );
};

AvatarFallback.displayName = 'AvatarFallback';
```

```tsx
import type { FC, Ref } from 'react';
// …existing imports…

export type FileUploadTriggerProps = ButtonProps;

/**
 * "Select file" button — the compact picker for when space is tight. Takes every
 * `Button` prop (defaults: primary / brand / large). Hidden (read-only) and blocked like the Area.
 *
 * `asChild`: no Button is rendered. The single child element (e.g. `<Avatar asChild><button/></Avatar>`)
 * becomes the trigger and receives `data-slot`, `data-testid`, `aria-describedby`, `disabled` and the
 * Ark trigger props. Button-only props (`variant`, `color`, `size`, `loading`, `fullWidth`, `as`) are
 * ignored. Pass `disabled` / `aria-describedby` here, not on the child — a child value wins the merge.
 */
export const FileUploadTrigger: FC<FileUploadTriggerProps> = ({
  children,
  disabled,
  asChild = false,
  'data-testid': testIdProp,
  'aria-describedby': describedByProp,
  ...props
}) => {
  const ctx = useRequiredFileUploadRootContext('FileUploadTrigger');
  const testId = useTestId('trigger', testIdProp);

  if (ctx.pickerHidden) return null;

  // A consumer hint is kept; the error link is added to it, never replaced.
  const describedBy =
    [describedByProp, ctx.rejections.length ? ctx.errorId : undefined].filter(Boolean).join(' ') ||
    undefined;

  const shared = {
    'aria-describedby': describedBy,
    'data-slot': 'file-upload-trigger',
    'data-testid': testId,
    disabled: disabled || ctx.pickerBlocked,
  };

  if (asChild) {
    // Button-only props must not reach the DOM.
    const { variant, color, size, loading, fullWidth, as, ref, ...rest } = props;
    return (
      <ArkFileUpload.Trigger {...rest} {...shared} ref={ref as Ref<HTMLButtonElement>} asChild>
        {children}
      </ArkFileUpload.Trigger>
    );
  }

  return (
    <ArkFileUpload.Trigger asChild>
      <Button variant='primary' color='brand' size='large' {...props} {...shared}>
        {children ?? (
          <>
            <Share />
            Select file
          </>
        )}
      </Button>
    </ArkFileUpload.Trigger>
  );
};
```

```ts
import { useEffect, useState } from 'react';

/**
 * An object URL for previewing a picked file (e.g. in `AvatarImage`), revoked when the file
 * changes or the component unmounts. The effect manages the blob URL's lifetime — an external
 * resource, not derived state.
 */
export const useFilePreviewUrl = (file?: File | null): string | undefined => {
  const [url, setUrl] = useState<string>();

  useEffect(() => {
    if (!file) {
      setUrl(undefined);
      return;
    }
    const next = URL.createObjectURL(file);
    setUrl(next);
    return () => URL.revokeObjectURL(next);
  }, [file]);

  return url;
};
```
